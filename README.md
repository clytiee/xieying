# Element Screenshot 元素截图
A practical browser extension for precise DOM element screenshot.
一款精准截取网页DOM元素的浏览器扩展，支持元素截图、滚动长截图。

## ✨ Features 功能
- 🎯 Precisely select any DOM element on webpage for screenshot
  精准选取网页上任意DOM元素进行截图
- 📜 Scrollable long screenshot for overflow content beyond viewport
  支持超出视口的滚动长截图
- 🧹 Auto‑hide fixed/sticky floating UI (toolbar, header, banner) for clean capture
  自动临时隐藏固定/悬浮工具栏、导航栏，获得干净截图
- 💾 Download screenshot image locally
  截图直接下载到本地
- 📋 Copy screenshot image to system clipboard
  截图复制到系统剪贴板，直接粘贴文档、聊天框
- ⌨️ Keyboard shortcut: Up‑arrow to select parent element
  键盘方向上键，向上选取父级元素

## 🔒 Privacy 隐私说明
All screenshot processing runs **locally inside your browser**.
No webpage content, browsing history or personal data will be collected or uploaded to any remote server.
所有截图处理完全在浏览器本地完成，不会收集、上传任何网页内容、浏览记录与个人数据。

### Official Edge Add‑on Store（推荐官方商店安装）
> 适用于 Microsoft Edge、其他 Chromium 内核浏览器
[Element Screenshot 元素截图 - Edge Add‑ons](https://microsoftedge.microsoft.com/addons/detail/element-screenshot-%E5%85%83%E7%B4%A0%E6%88%AA%E5%9B%BE/cankohhkjjiicdjgggoiifeengdaefkj)

### Install from source code 源码本地加载（开发者）
1. Clone / download this repository to local disk
2. Open browser extension page: `edge://extensions/` or `chrome://extensions/`
3. Turn on **Developer mode**（开发者模式）
4. Click `Load unpacked`，select project root folder.

## 🛠 Usage 使用
1. Click extension icon on browser toolbar, enter element selection mode.
2. Hover mouse over page element, click to capture screenshot.
3. Pop‑up menu appears, you can copy image or download image file.
4. Press `ESC` to exit selection mode.

1. 点击浏览器工具栏扩展图标，进入元素选取模式
2. 鼠标悬浮网页元素，点击即可截取该元素
3. 弹出操作菜单，支持复制截图、下载图片文件
4. 按 `ESC` 退出选取模式
